# Notre jeu d'amour — application mobile installable

Cette version est une Progressive Web App (PWA) : elle reste hébergée sur GitHub Pages et peut être ajoutée à l'écran d'accueil d'un téléphone. Le service worker met en cache les fichiers principaux pour une ouverture ultérieure hors connexion après le premier chargement.

## Android
1. Ouvrir https://madjadoumcyrille-ux.github.io/Karen-and-Cyrille/ dans Chrome.
2. Ouvrir le menu ⋮.
3. Choisir « Installer l'application » ou « Ajouter à l'écran d'accueil ».

## iPhone / iPad
1. Ouvrir le lien dans Safari.
2. Toucher le bouton Partager.
3. Choisir « Sur l'écran d'accueil », puis « Ajouter ».

Note : c'est une application web installable, pas un fichier APK ni une application publiée sur les stores.
